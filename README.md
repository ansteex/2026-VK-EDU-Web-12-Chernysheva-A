# Aski Haski

Учебный сервис вопросов и ответов, разработанный на Django.

## Структура проекта

- `application` — настройки и основная конфигурация Django;
- `questions` — страницы вопросов, популярных вопросов, тегов и создания вопроса;
- `core` — страницы входа, регистрации и профиля;
- `templates` — общие шаблоны страницы;
- `public/static` — CSS, JavaScript и изображения;
- `public` — статические HTML-страницы первого домашнего задания.

## Запуск через Docker

1. Собрать образ и запустить контейнер:

   ```bash
   docker compose up --build
   ```

2. Открыть в браузере:

   ```text
   http://localhost:8000
   ```

3. Для остановки контейнера нажать `Ctrl+C`, затем выполнить:

   ```bash
   docker compose down
   ```

## Страницы проекта

- `/` — список новых вопросов;
- `/hot/` — популярные вопросы;
- `/tag/python/` — вопросы по тегу;
- `/question/1/` — страница вопроса и ответов;
- `/ask/` — создание вопроса;
- `/login/` — вход;
- `/signup/` — регистрация;
- `/profile/` — настройки профиля.

## Технологии

- Python 3.12;
- Django 5.2;
- HTML;
- CSS;
- Bootstrap;
- Docker и Docker Compose.
